# MEMORY INDEX — Control Plane #2a

**Version:** 2.0.1 (2026-08-19)
**Owner:** memory-steward (Knowledge Commons)

Memory architecture for Agentverse. Governs what is persisted, where, by whom, and for how long.

## 1. Memory layers

| Layer | Location | Owner | Purpose |
|-------|----------|-------|---------|
| L0 Shared graph memory | `/home/coder/project/.memory/memory.json` (memory MCP server) | memory-steward | durable entity/relationship facts (deployments, containers, services) |
| L1 Operational index | `AGENTVERSE/MEMORY_INDEX.md` (this file) | memory-steward | table of contents for L0 + session-scoped facts |
| L2 Knowledge base | `AGENTVERSE/KNOWLEDGE_BASE.md` | knowledge-curator | validated decisions, issue records, proficiency records |
| L3 Control planes | `AGENTVERSE/*.md`, `AGENT_REGISTRY.json` | org leads | the org's own operating state |

## 2. Write policy

- **Who may write:** memory-steward (L0/L1); knowledge-curator (L2); org leads (L3). All other agents propose via evidence; stewards index.
- **What is written:** durable facts only (deployments, config, decisions, resolved issues, learned conventions). No transient state, no raw chat.
- **Format:** key facts as entity observations in `.memory/memory.json`; index entries as one-line bullets below.

## 3. Indexing convention

Entry format in this file:
`[YYYY-MM-DD] <topic> — <one-line fact> — <source agent> → <owner action>`

## 4. TTL & retirement

- Operational facts (L1): retire after 90 days unless promoted to L2.
- Knowledge entries (L2): persist; retire only with a recorded reason by knowledge-curator.
- Deployment facts (L0): persist while the deployment exists.

## 5. Search convention

- All agents search L2 first, then L0/L1, then the codebase. Cite `file` + entry when relying on a memory fact.
- Conflicting memory vs code: **code wins**; steward files a correction.
