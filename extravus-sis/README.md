# Extravus Student Information System

## Project Overview
Complete rebranding of RosarioSIS to Extravus with enhanced features and comprehensive currency support.

## Features
- ✅ Full system rebranding from RosarioSIS to Extravus
- ✅ Working login system (admin/admin)
- ✅ Installation poll page integration
- ✅ Comprehensive world currency support (80+ currencies)
- ✅ Continental currency organization
- ✅ Clean error-free operation

## Access Information
- **URL:** http://localhost:8084
- **Login:** admin / admin
- **Configuration:** School Setup → Configuration → School Tab

## Currency System
Supports 80+ world currencies organized by continent:
- North America (8 currencies)
- Europe (12 currencies) 
- Asia (15 currencies)
- Africa (12 currencies)
- South America (10 currencies)
- Oceania (6 currencies)
- Middle East (12 currencies)
