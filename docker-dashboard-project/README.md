# Docker Dashboard Project

## Project Overview
Advanced Docker management platform with real-time monitoring and container management capabilities.

## Features
- 🐳 Real-time Docker container monitoring
- 📊 Interactive dashboard interface
- ⚡ Container management (start/stop/restart)
- 🔧 Network visualization
- 📱 Responsive design
- 🚀 Auto-refresh functionality

## Access Information
- **URL:** http://localhost:8888
- **Start Script:** `./docker-projects/start-dashboard.sh`

## Files Structure
- `server.py` - Python Flask server
- `dashboard.html` - Main dashboard interface
- `dashboard.js` - JavaScript functionality
- `enhanced-dashboard.html` - Enhanced version
- `start-dashboard.sh` - Startup script
- `manage.sh` - Management utilities
